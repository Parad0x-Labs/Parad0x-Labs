# Parad0x Labs

Open-source tools for people who want their software, their AI and their money to stay under their own control.

## VOOL: your machine, your agent

[**VOOL**](https://github.com/Parad0x-Labs/vool) is a local-first personal agent. It reads a project, edits files, runs tests, researches the web and carries useful context into the next session.

- Runs a local model by default through Ollama, with no account or cloud key needed. Bring your own cloud provider when you want one.
- Memory across sessions that you can inspect and manage.
- Workspace scopes, operating modes and permission checks decide what the agent may do.
- Tool activity is recorded, with signed receipts you can verify offline.
- Current version: **0.6.0 beta**, installed from source. macOS on Apple Silicon is the main target, Linux is covered in CI, Windows is experimental. MIT licensed. Site: [vool.dev](https://vool.dev/).

**Coming in 0.7:** signed releases for Windows, Linux and macOS on Apple Silicon and Intel.

## Agent payments and privacy on Solana

- [**dna-x402**](https://github.com/Parad0x-Labs/dna-x402): payment rails for AI agents. x402 micropayments on Solana with netting, transfer and stream settlement, and on-chain receipt anchoring.
- [**Dark-Null-Protocol**](https://github.com/Parad0x-Labs/Dark-Null-Protocol): privacy settlement for Solana with a published Groth16 proof stack (circuit, verifying key, Rust verifier, manifest).
- [**openclaw-skills**](https://github.com/Parad0x-Labs/openclaw-skills): encrypted vault, ZK settlement archiving, x402 payment receipts, Agent Passport binding and Solana anchoring for agent runtimes.
